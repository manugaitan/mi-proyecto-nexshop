# NexShop Group S.A.

**Alumno:** Manu Gaitán

## Descripción del proyecto

NexShop Group S.A. es una empresa ficticia dedicada a la venta de productos tecnológicos tanto a través de comercio electrónico como mediante tiendas físicas distribuidas por diferentes ciudades.

El proyecto consiste en el análisis, diseño e implementación de una base de datos relacional que permita gestionar clientes, productos, proveedores, pedidos online, ventas presenciales, logística, promociones e incidencias.

## Instrucciones de uso

1. Crear una base de datos llamada `nexshop`.
2. Ejecutar el archivo `sql/schema.sql`.
3. Ejecutar el archivo `sql/datos.sql`.
4. Ejecutar las consultas incluidas en `consultas/consultas.sql`.
